# Фитнес трекер

Веб-приложение (PWA) для iPhone: тренировки по дням, календарь, таймер отдыха, веса по подходам, видео техники.
Работает без интернета, данные хранятся на телефоне.

## Как выложить бесплатно (GitHub Pages), один раз

1. Зарегистрируйся на https://github.com
2. Справа сверху «+» → **New repository** → имя, например `fitness` → **Public** → **Create repository**.
3. На странице репозитория нажми **uploading an existing file** и перетащи **все файлы и папку `icons`** из этой папки → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты приложение будет по адресу `https://ТВОЙ-ЛОГИН.github.io/fitness/`.

## Установка на iPhone

Открой этот адрес в **Safari** → «Поделиться» → **«На экран „Домой“»** → «Добавить».

## Обновление

Если меняешь файлы — загрузи их заново в репозиторий (п. 3). Перед этим поменяй
`fitapp-v1` на `fitapp-v2` в `sw.js`, чтобы телефон точно подхватил новую версию.
Твои данные при обновлении не пропадают.

## Мини-апп в Telegram

Сначала выложи сайт на GitHub Pages (см. выше) — Telegram открывает только https-адреса.

1. Открой в Telegram **@BotFather** → `/newbot` → имя (например «Мой фитнес») → username,
   который заканчивается на `bot` (например `my_fitness_tracker_bot`).
2. `/mybots` → выбери бота → **Bot Settings** → **Menu Button** → **Configure menu button** →
   пришли адрес `https://ТВОЙ-ЛОГИН.github.io/fitness/` → название кнопки, например `Тренировка`.
3. Открой своего бота → нажми **Start** → внизу слева появится кнопка «Тренировка» — это и есть приложение.
4. Закрепи чат с ботом (свайп вправо → «Закрепить»), чтобы он всегда был сверху.

По желанию — прямая ссылка на приложение: в @BotFather `/newapp` → выбери бота → название,
описание, картинка 640×360 → тот же адрес → короткое имя, например `app`.
Получится ссылка вида `t.me/my_fitness_tracker_bot/app`.

В Telegram данные автоматически сохраняются в **облако Telegram**, поэтому они не пропадут
и будут на любом твоём устройстве. С приложением на экране «Домой» эти данные не общие,
но их можно перенести через ⚙︎ → «Сохранить копию» / «Загрузить копию».

## Резервная копия

⚙︎ → «Сохранить копию» — файл можно положить в «Файлы»/iCloud. «Загрузить копию» — восстановить.
